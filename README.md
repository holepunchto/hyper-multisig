# hyper-multisig

- Create multisig core from public keys of multiple signers
- Sign core with signatures of multiple signers

## Usage

Use [hyper-multisig-cli](https://github.com/holepunchto/hyper-multisig-cli)

## Multisig Flow

- Step 1: Use [hypercore-sign](https://github.com/holepunchto/hypercore-sign) to generate a pair of secret key and public key. Later, public keys from all signers will be collected to create multisig core.

  ```shell
  hypercore-sign generate-keys

  # to create an additional key pair
  HYPERCORE_SIGN_KEYS_DIRECTORY=<path-to-another-dir> hypercore-sign generate-keys
  ```

- Step 2: Use HyperMultisig to create multisig core given the public keys from the previous step, and a repo path which is used to generate repo-path-based namespace to avoid collision.

  ```js
  // collect public keys of all signers generated by hypercore-sign
  const publicKeys = ['o37a1...', 'qgbd9...', '6r66j...']

  // to avoid collision, we structure namespace based on repo path
  const namespace = 'holepunchto/my-repo'

  const store = new Corestore('storage')
  await store.ready()

  const multisig = new HyperMultisig(store)
  const { manifest, core } = await multisig.createCore(publicKeys, namespace)
  ```

- Step 3: Use [hypercore-signing-request](https://github.com/holepunchto/hypercore-signing-request) to generate signing request on a normal core (non-multisig) with the manifest from the previous step.

  ```js
  const { generate } = require('hypercore-signing-request')

  const fromCore = store.get({ name: 'my-core' })
  await fromCore.ready()

  fromCore.append('hello world 1')
  fromCore.append('hello world 2')
  fromCore.append('hello world 3')

  const signingRequest = await generate(fromCore, { manifest })
  ```

- Step 4: Use [hypercore-sign](https://github.com/holepunchto/hypercore-sign) to sign the signing request to generate a signature. Later, signatures from all signers will be collected to sign the multisig core.

  ```shell
  hypercore-sign <signingRequest>
  ```

- Step 5: Use HyperMultisig to sign the multisig core with the signatures from the previous step.

  ```js
  const MultisigUtil = require('hyper-multisig/lib/util')

  // collect signatures from all signers generated by hypercore-sign
  const signatures = [signature1, signature2, ...]

  const batch = await MultisigUtil.signCore(multisigCore, fromCore, signatures, {
    commit: true // set to false for dry run
  })
  ```
